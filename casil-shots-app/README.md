# Casil Shots

A frontend-only photography portfolio built with Vue 3, Vite, Vue Router and Motion for Vue. All content and interactions are demonstrations; no backend, authentication, booking delivery, or private photo storage is included.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` for a production build.

Favorites, demo inquiries, and media manager edits use localStorage in the current browser only. The login and client gallery are simulations, and bundled assets/data can be inspected by visitors. Inquiry forms do not send email. Replace sample photos, sample prices, and testimonials with owned/licensed content before publishing.
